Banjo & Kong: Jiggy Jungle - Windows test build (not a release)

1. Unzip anywhere and run DK64Recompiled.exe (Windows 10 or 11, 64-bit).
2. In the launcher, pick "Load DK64 ROM" and choose your Donkey Kong 64 (USA) ROM.
   Optionally pick "Load Banjo-Kazooie ROM" (USA 1.0) for the Banjo crossover bits.
3. Press Start Game.

No ROMs are included. Your ROMs and saves are stored in %LOCALAPPDATA%\JiggyJungle.
If Windows SmartScreen warns about an unknown app, choose "More info" then "Run anyway".
